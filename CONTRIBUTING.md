# Contributing to Math Tapper / المساهمة في Math Tapper

## English

Thank you for your interest in contributing to Math Tapper! This document provides guidelines for contributing to the project.

### How to Contribute

1. **Fork the Repository**
   - Click the "Fork" button at the top right of the repository page

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Math-Tapper-By-Copilot.git
   cd Math-Tapper-By-Copilot
   ```

3. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Your Changes**
   - Follow the existing code style
   - Add comments where necessary
   - Update documentation if needed

5. **Test Your Changes**
   - Build the app and test on a real device
   - Ensure all features work correctly
   - Test on different Android versions if possible

6. **Commit Your Changes**
   ```bash
   git add .
   git commit -m "Description of your changes"
   ```

7. **Push to Your Fork**
   ```bash
   git push origin feature/your-feature-name
   ```

8. **Create a Pull Request**
   - Go to the original repository
   - Click "New Pull Request"
   - Select your fork and branch
   - Provide a clear description of your changes

### Code Style Guidelines

- Use meaningful variable and method names
- Follow Java naming conventions:
  - Classes: PascalCase
  - Methods: camelCase
  - Constants: UPPER_SNAKE_CASE
- Add Javadoc comments for public methods
- Keep methods focused and concise
- Use proper indentation (4 spaces)

### Areas for Contribution

We welcome contributions in the following areas:

1. **Feature Enhancements**
   - Support for more complex math operations
   - Improved OCR accuracy
   - Better region selection UI
   - Performance optimizations

2. **Bug Fixes**
   - Report bugs via GitHub Issues
   - Include steps to reproduce
   - Provide device and Android version information

3. **Documentation**
   - Improve existing documentation
   - Add tutorials or examples
   - Translate to additional languages

4. **Testing**
   - Test on different devices
   - Report compatibility issues
   - Suggest improvements

### Reporting Issues

When reporting issues, please include:

- **Device Information**: Model, Android version
- **App Version**: Check in About section
- **Steps to Reproduce**: Clear, step-by-step instructions
- **Expected Behavior**: What should happen
- **Actual Behavior**: What actually happens
- **Screenshots**: If applicable

### Feature Requests

We welcome feature requests! Please:

- Check if the feature already exists
- Search existing issues to avoid duplicates
- Clearly describe the feature and its benefits
- Explain your use case

### Code of Conduct

- Be respectful and constructive
- Welcome newcomers and help them learn
- Focus on what is best for the project
- Show empathy towards other contributors

### Questions?

If you have questions about contributing, feel free to:

- Open an issue with the "question" label
- Check existing documentation
- Review closed issues for similar questions

Thank you for contributing to Math Tapper!

### إرشادات نمط الكود

- استخدم أسماء متغيرات وطرق ذات معنى
- اتبع اصطلاحات تسمية Java:
  - الفئات: PascalCase
  - الطرق: camelCase
  - الثوابت: UPPER_SNAKE_CASE
- أضف تعليقات Javadoc للطرق العامة
- اجعل الطرق مركزة وموجزة
- استخدم المسافات البادئة المناسبة (4 مسافات)

### مجالات المساهمة

نرحب بالمساهمات في المجالات التالية:

1. **تحسينات الميزات**
   - دعم عمليات رياضية أكثر تعقيداً
   - تحسين دقة OCR
   - واجهة مستخدم أفضل لاختيار المناطق
   - تحسينات الأداء

2. **إصلاح الأخطاء**
   - الإبلاغ عن الأخطاء عبر GitHub Issues
   - تضمين خطوات إعادة الإنتاج
   - توفير معلومات الجهاز وإصدار أندرويد

3. **التوثيق**
   - تحسين التوثيق الموجود
   - إضافة دروس أو أمثلة
   - الترجمة إلى لغات إضافية

4. **الاختبار**
   - الاختبار على أجهزة مختلفة
   - الإبلاغ عن مشاكل التوافق
   - اقتراح تحسينات

### الإبلاغ عن المشاكل

عند الإبلاغ عن المشاكل، يرجى تضمين:

- **معلومات الجهاز**: الطراز، إصدار أندرويد
- **إصدار التطبيق**: تحقق في قسم About
- **خطوات إعادة الإنتاج**: تعليمات واضحة خطوة بخطوة
- **السلوك المتوقع**: ما الذي يجب أن يحدث
- **السلوك الفعلي**: ما يحدث فعلياً
- **لقطات الشاشة**: إن وجدت

### طلبات الميزات

نرحب بطلبات الميزات! يرجى:

- التحقق من وجود الميزة بالفعل
- البحث في المشاكل الموجودة لتجنب التكرار
- وصف الميزة وفوائدها بوضوح
- شرح حالة الاستخدام الخاصة بك

### قواعد السلوك

- كن محترماً وبنّاءً
- رحب بالقادمين الجدد وساعدهم على التعلم
- ركز على ما هو الأفضل للمشروع
- أظهر التعاطف تجاه المساهمين الآخرين

### أسئلة؟

إذا كانت لديك أسئلة حول المساهمة، لا تتردد في:

- فتح issue مع تسمية "question"
- التحقق من التوثيق الموجود
- مراجعة المشاكل المغلقة للأسئلة المشابهة

شكراً لمساهمتك في Math Tapper!
